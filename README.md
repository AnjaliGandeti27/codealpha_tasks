# 1. 🔗 Simple URL Shortener

A backend-based URL Shortener developed using **Node.js, Express.js, MongoDB, and Mongoose**.

## Main Features

* Accept a long/original URL
* Validate the URL
* Generate a short code
* Store URL mappings in MongoDB
* Retrieve the original URL using the short code
* Handle invalid and missing URL input
* REST API based backend

## Technologies

* Node.js
* Express.js
* MongoDB
* Mongoose
* Postman

# 3. 🍽️ Restaurant Management System

A backend-based Restaurant Management System developed using **Node.js, Express.js, MongoDB, and Mongoose**.

## Main Features

* Manage restaurant menu items
* Create and manage customer orders
* Manage restaurant tables
* Create and manage table reservations
* Manage restaurant inventory
* Calculate order totals automatically
* Check menu item availability
* Check inventory before creating orders
* Prevent insufficient inventory orders
* Automatically reduce inventory when an order is placed
* Restore inventory when an order is cancelled
* Check table availability for reservations
* Prevent duplicate reservations
* Validate reservation guest capacity
* Link orders with reservations when required
* Update order and reservation status
* Store order, reservation, menu, table, and inventory information in MongoDB

## Technologies

* Node.js
* Express.js
* MongoDB
* Mongoose
* Postman
